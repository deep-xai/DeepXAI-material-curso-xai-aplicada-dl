# Material del curso de XAI aplicada al Deep Learning

Bienvenido/a al repositorio con el material del curso. Este repositorio contiene todo el material para aprender explicabilidad e interpretabilidad en Deep Learning, incluyendo teoría, ejemplos en Python y ejercicios prácticos. Durante todo el curso, os acompañará el doctor <a href="https://www.linkedin.com/in/christian-oliva-moya-ingeniero/">Christian Oliva Moya</a>, experto en explicabilidad de redes neuronales profundas.
